# Mathe-Übung: Funktionen

Übungsseite für: Funktionen erkennen und darstellen, Steigung von Geraden, proportionale Funktionen, lineare Funktionen.
Mit Beispielen, Aufgaben, Tabellen, Koordinatensystemen und einem Test über alle Themen.

## Als Webseite veröffentlichen (GitHub Pages)

1. Auf github.com ein neues Repository anlegen (z. B. `mathe-uebung`), Sichtbarkeit: Public.
2. Die Dateien `index.html` und `README.md` hochladen (Add file → Upload files) und committen.
3. Im Repo: Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
4. Nach ca. einer Minute ist die Seite erreichbar unter `https://DEIN-NAME.github.io/mathe-uebung/`.

Die Seite ist eine einzelne HTML-Datei und braucht keine Installation.
